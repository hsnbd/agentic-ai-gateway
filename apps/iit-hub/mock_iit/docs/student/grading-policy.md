# Grading policy

Course marks are made up of: attendance 10%, class tests and assignments 30%,
midterm examination 20%, and final examination 40%.

| Marks   | Grade | Grade point |
|---------|-------|-------------|
| 80–100  | A+    | 4.00 |
| 75–79   | A     | 3.75 |
| 70–74   | A-    | 3.50 |
| 65–69   | B+    | 3.25 |
| 60–64   | B     | 3.00 |
| 50–59   | C     | 2.50 |
| below 50| F     | 0.00 |

A student needs at least **75% attendance** to sit the final examination.
A failed course (F) must be retaken; the better grade counts. Students whose
CGPA falls below 2.50 are placed on academic probation for one semester.
