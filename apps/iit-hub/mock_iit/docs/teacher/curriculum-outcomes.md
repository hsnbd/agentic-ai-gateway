# Curriculum outcomes (faculty)

The BSSE curriculum is mapped to program learning outcomes (PLOs):

- PLO1: Apply software engineering principles across the full life cycle.
- PLO2: Design, implement and test software systems of realistic size.
- PLO3: Work effectively in teams and communicate technical work.
- PLO4: Act professionally and ethically.

Every course outline lists which PLOs it assesses. Course teachers report PLO
attainment at the end of each semester; an attainment below 60% for a PLO
triggers a course review by the curriculum committee.
